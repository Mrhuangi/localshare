LocalShare

局域网文件传送，像 AirDrop 一样简单。在一台电脑上运行这个服务，同一 Wi-Fi 里的手机和其他电脑打开页面，就能互相传文件。

文件在设备之间直连传输（WebRTC），不经过服务器，也不需要互联网。服务器只负责让设备彼此发现对方。

运行

需要 Node.js 18 或以上。

    npm install
    npm start

启动后终端会显示地址，在每台设备的浏览器里打开即可。本机是 http://localhost:7070 ，其他设备用终端里显示的局域网地址。

使用

页面左侧是在线的设备。点选一台，把文件拖进来，或者点「选择文件」，对方确认后开始传输。一批文件只需确认一次。也可以给所选设备发送一段文字或链接。

传输是分片流式的，进度、速度和剩余时间都是实时的，可以随时取消。直连建立不了时会自动退回经服务器分片中转，功能不受影响。

一点限制

接收方在浏览器里收到完整文件后另存到下载文件夹，单个文件建议不超过 2 GB，太大的文件会受浏览器内存限制。
